# 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 无法加载 DLL / WinError 193 / BadImageFormatException | 必须 Windows、32 位调用进程；64 位 Windows 不代表程序应编译为 64 位 |
| DLL 存在但提示找不到模块 / WinError 126 | 保留完整发布目录，检查依赖及系统运行库；不要从不可信网站单独下载 DLL |
| 登录失败 | 查看 ErrInfo，核对券商标识、账号、密码和接入配置；不继续用失败的 ClientID 查询 |
| `BROKER_A` 不识别 | 这是示例占位值，按所提供接入配置替换 |
| 中文乱码 | ErrInfo 使用 GB18030；示例转换成 Unicode，业务 JSON 按 UTF-8 解析 |
| 查询空数组 | 空结果不是错误，不要把缺失字段或 null 当作数字 0 |
| 信用类查询不支持 | 确认账户类型、权限与运行包的功能支持 |
| ErrInfo 为空但 accepted 为 false | 属于券商业务拒绝，查看 message |
| accepted 为 null／缺失，或交易调用超时 | 结果不确定；先核对当日委托／成交，不自动重发 |
| 撤单 accepted 为 true 但委托仍在 | 仅表示请求受理，需查询最终订单状态 |

示例不自动重连、切换账号或重试交易。明确会话失效后，由调用方显式退出并重新登录，再查询核对；不能借重新登录直接重发上一笔交易。

不得将密码、授权文件或含完整账户信息的日志附到公开 Issue。购买与私下接入咨询见 [首页微信二维码](../README.md#购买与接入咨询)。
